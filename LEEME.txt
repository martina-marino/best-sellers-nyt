CAMBIOS DE ESTA ENTREGA
- Tarjetas de libros: escala proporcional al ancho, sin límite vertical que reducía las portadas.
- Los protagonistas: presentación y carpetas condensadas para pantallas de escritorio. El tamaño final varía según la altura de la ventana y la carga de los iframe de Flourish.
- Explorá un autor: se redujo el alto de la introducción, buscador y resultados; por defecto se muestran hasta tres títulos, con opción a desplegar el resto.
- Sugerencias de autores: se corrigen puntos finales espurios y comillas completas, se agrupan las variantes tipográficas y se excluyen atribuciones rotas o no identificadas. El archivo autores-data.js original no fue modificado. Las coautorías siguen como aparecen en la fuente.

Probar en navegador, tanto en escritorio como en móvil, al publicar: el contenido y alto de las visualizaciones Flourish dependen de un servicio externo.

Git: desde el repositorio ejecutar git add index.html styles.css script.js autores-data.js && git commit -m "Ajustes finales de tarjetas, autores y buscador" && git push origin main
